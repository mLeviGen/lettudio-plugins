# Lettudio plugins

Официальные плагины и темы для [Lettudio](https://github.com/mLeviGen/lettudio).

- `catalog.json` — каталог, который приложение читает по умолчанию.
- Каждая папка — отдельный плагин (`plugin.json` + файлы). Архивы для установки лежат в [релизах](https://github.com/mLeviGen/lettudio-plugins/releases/latest).
- `PROTOCOL.md` — как устроены плагины и каталог; `sdk/` — помощник для Python-плагинов.
