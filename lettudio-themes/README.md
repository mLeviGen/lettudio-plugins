# Темы Lettudio (`lettudio-themes`)

Мультипресетный и полностью настраиваемый плагин оформления для **ПК и телефона** (протокол 3, тип `theme`).

## Что внутри

- **Antigravity** — глубокий тёмный фон (`#0C0E14`) и сине-индиго акценты (`#7AA2F7`).
- **Discord** — фирменная палитра Discord Dark (`#1E1F22` / `#2B2D31`) и Blurple (`#5865F2`).
- **OLED** — чистый чёрный фон (`#000000`) для AMOLED-экранов с минималистичными контрастами.
- **Кастомная** — ваша собственная палитра с живым редактором прямо в приложении.

## Кастомная настройка цветов и интерфейса

Нажмите **«Настроить цвета»** в карточке плагина в **Настройки → Плагины**:

- можно скопировать любой готовый пресет за основу;
- изменить все 9 цветовых токенов (`bg`, `surface`, `surfaceHi`, `fill`, `text`, `muted`, `accent`, `coverA`, `coverB`) через палитру, слайдеры R/G/B или `#RRGGBB` hex-код;
- настроить скругление панелей (`radius` 0–28), форму обложек (`circle` / `rounded` / `square`), плотность списков (`compact` / `normal` / `comfortable`) и подписи навигации (`active` / `all` / `none`).

Все изменения применяются мгновенно и сохраняются отдельно для пресета `Кастомная`, поэтому переключение на `Antigravity`, `Discord` или `OLED` и обратно не затирает ваши цвета.

## Установка

1. Откройте в Lettudio **Настройки → Плагины**.
2. Нажмите **«Установить (.zip / JSON)»** (выберите `plugin.json` из папки `plugins/lettudio-themes` или `.zip`-архив) либо **«Из папки»** (выберите `plugins/lettudio-themes`).
3. Плагин включится автоматически и будет работать на Windows, Linux, macOS и Android.
