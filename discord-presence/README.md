# Discord Presence

Показывает в статусе Discord текущий трек: «Слушает Lettudio». В статусе видно название, исполнителя, обложку и полоску прогресса. На паузе статус пропадает.

## Как включить
Lettudio → «Плагины» → включи **Discord Presence**. Больше ничего настраивать не нужно: плагин сам находит Discord на этом ПК. Если Discord запущен позже или перезапущен, статус вернётся в течение 15 секунд.

Нужен Python 3 в PATH, внешние библиотеки не требуются.

## Своё приложение (необязательно)
Чтобы в статусе было другое имя, создай приложение на https://discord.com/developers/applications и впиши его **Application ID** в `config.json` → `client_id`. Картинка с ключом из `large_image` показывается, когда у трека нет обложки по ссылке.
